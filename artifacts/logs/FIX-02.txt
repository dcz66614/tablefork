6. 决定与说明

D1. verify:release 本卡不跑：review/RELEASE_MANIFEST.json 是旧冻结
    （base 4025061、spec 1.0.1）的清单，跑它必然 FAIL，与本卡改动无关；

    只比 inputHash / spec_version（见 §2）。Worker/CLI/UI 三路的
    jobId 由各自调用方传入，已逐路实测。

    INVALID_RAGGED_GRID），不只依赖 TS 类型：Worker/CLI 的 JS 调用
    方若漏传也不会静默产出无 jobId 的报告。
D4. docx 未从 md 重排生成（见 §4）：无可靠生成方法记录，定向 run
    文本替换 + 渲染核对是与 S0 一致的做法；md 与 docx 已逐项核对一致。
