## 4. Implemented functions (public API of witness.ts)
witness.ts imports only frozen contracts and T003/T004 modules
(types from './index'; flattenGrid from './flatten'; buildGrid from './grid';
buildHeaderPaths from './headers'; parseValidatedTable from './parse'):
- findWitness(html: string, strategy: Strategy): WitnessResult — the main
  entry. Parses A, enumerates merged cells sorted by (extra_slots asc,
  origin row, origin col, cellId), builds each B with buildAlternativeHtml,
  re-parses/re-grids B with T003, byte-compares F_p(A) vs F_p(B) (UTF-8,
  J-T004-1 trailing-LF口径), compares canonical cell graphs, picks the
  first header-changing success else the first structural success;
  returns CERTIFIED_COLLISION + CollisionProof + CollisionKind, or
  NO_WITNESS_FOUND + reason. Invalid input throws TableForkInputError
  (J-T005-3), it is never reported as NO_WITNESS_FOUND.
- canonicalCellGraph(grid: GridResult): string — canonical JSON (fixed key
  order, no whitespace) { rows, cols, cells (all fields), slotOwner }
  (J-T005-4).
- sha256Utf8(text: string): string — SHA-256 hex over the UTF-8 bytes.
- utf8BytesEqual(a, b: string): boolean — strict UTF-8 byte equality
  (TextEncoder, not JS string ==).
- splitCost(cell: Cell): number — extra_slots = rowSpan*colSpan - 1.
- headerPathsChanged(gridA, gridB: GridResult): boolean — per-slot
  rowHeaders/colHeaders text-array comparison via buildHeaderPaths
  (J-T005-5); unknown titles (empty on both sides) do not count as changed.
- collisionKindOf(headerAssociationChanged: boolean): CollisionKind —
  HEADER_ASSOCIATION_CHANGED iff true, else STRUCTURAL_COLLISION.
- buildAlternativeHtml(parsed, grid, source, strategy): string — rebuilds B:
  same rows/cols/sections, every row keeps its <tr> (even a row with no
  origin cells), source cell split into 1x1 pieces (origin copies text,
  extensions blank under ORIGIN_EMPTY / same text under REPEAT_VALUE),
  role/scope/section preserved (J-T005-2), other cells verbatim, cells
  emitted left-to-right per row, caption preserved if present.
All functions are pure (no random/time/env/IO); repeated findWitness calls
return byte-identical proofs (see §8 determinism test).

## 7. Hash semantics (what each SHA-256 is computed over)
- aGraphSha256: SHA-256 (hex) of the UTF-8 bytes of canonicalCellGraph(gridA),
  the canonical JSON { rows, cols, cells (all fields), slotOwner } (J-T005-4).
- bGraphSha256: same computation over canonicalCellGraph(gridB), where gridB
  is rebuilt by independently re-parsing alternativeHtml with T003
  parseValidatedTable + buildGrid (not copied from any internal state).
- markdownSha256: SHA-256 of the UTF-8 bytes of F_strategy(A) (flatten output
  string, trailing LF per J-T004-1); when certified, F_strategy(B) has
  byte-identical UTF-8 bytes (checked with utf8BytesEqual before certifying),
  so the same hash identifies both Markdown texts.

  TFK-B's equal T004's E5/E6 hashes (see §5/§6 notes) — three independent
  computations (T004 log, T005 CLI, T005 evidence script) agree.

## 9. Documented judgement calls (spec does not pin these down; see witness.ts header)
J-T005-1. Split is per-strategy (§5.2: extensions blank under ORIGIN_EMPTY,
    same text under REPEAT_VALUE). One B generally cannot collide under both
    strategies (unless the source text is empty). findWitness(html, strategy)
    certifies one strategy at a time; "both strategies collide" means two
    calls, two (usually different) B tables.
J-T005-2. Split pieces keep the source cell's role/scope/section; only the
    span becomes 1x1 and the text follows the strategy (§5.2 "保留原点所属
    rowgroup"). Consequence: under REPEAT_VALUE the repeated text restores
    the same declared header path, so TFK-B (and §6.3's colspan cell) certify
    as STRUCTURAL_COLLISION only under REPEAT_VALUE.
J-T005-3. Invalid/unsupported input throws TableForkInputError (same as
    parse/grid); NO_WITNESS_FOUND is only for valid input with no certifying
    candidate. The 'UNSUPPORTED' witness status is for the T008 report layer
    to map the thrown error to; this module does not swallow errors.
J-T005-4. Canonical cell graph = JSON (fixed key order, no whitespace)
    { rows, cols, cells (all fields incl. text), slotOwner }; text is part
    of structural identity (slot-to-cell ownership + text distribution).
J-T005-5. Header change = per-slot rowHeaders/colHeaders text-array
    comparison via frozen buildHeaderPaths; unknown titles (empty on both
    sides) never count as a change.
J-T005-6. B illegal is real: a legal A at the 128-cell cap yields 129-cell B
    tables rejected OVER_SIZE; such candidates are skipped, and if all fail
    the result is NO_WITNESS_FOUND with the rejection reasons recorded.
J-T005-7. §6.3 under REPEAT_VALUE selects the rowspan cell c00, not the
    colspan cell: the repeated '产品' text makes the col0 path
    ['产品','产品'] (§3.3 dedups by cellId only, not by text), so the rowspan
    split is header-changing too and precedes the colspan cell in
    (cost, row, col, id) order; the colspan split under REPEAT_VALUE is
    structural-only. ORIGIN_EMPTY still selects the colspan cell c01, exactly
    as the project book §6.3 says. This follows from frozen headers.ts plus
    the frozen selection order; it is not implementer discretion.
