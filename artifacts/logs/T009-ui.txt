## 7. 裁决小节（§7：规格未钉死的 UI 细节）
- J-T009-1（焦点高亮的具体形式）：悬停/聚焦一格时，左右表对应来源格加 3px 橙色描边，
  Markdown 对应行加底色 + 加粗 + 行号，并有一行文字说明“已选中槽位 R{r}C{c}”。
  颜色之外另有描边/加粗/文字三重信号，不单靠颜色。
- J-T009-2（“非法时禁用”的口径）：比较按钮仅在 HTML 为空或超 64 KiB 时禁用并说明原因；
  结构层面非法/不支持的输入（如 TFK-D 的 headers=、ragged grid）不预先禁用，
  而是点击后由分析报出 UNSUPPORTED / INVALID_INPUT 状态——否则 §4.2 的这两个状态
  在 UI 上不可达。输入框下方另有 parse+grid 试算提示（结构有效或错误码 + 定位），
  仅作提示，不作最终判定。
- J-T009-3（输入变化后的旧结果）：HTML、M、策略任一变化即清除旧结果与错误，
  回到 READY/EMPTY；不展示“对应旧输入”的过期结果，避免新旧混淆。
- J-T009-4（M 为空的口径）：与 compare.ts J-T007-1 一致，空串按 NOT_SUPPLIED；
  仅含空白的串按已提供处理。M 文本区留空时提示“留空表示未提供 M”。
- J-T009-5（交接稿头）：复制/展示的交接稿在逐格行之前加 4 行注释头（报告 schema、
  预设与策略、MISMATCH 时的证书适用范围警告、未知标题写 ? 的提醒）；逐格行本身
  一字不改地复用 records.ts 的 formatSlotFacts。下载的 JSON 就是 AnalyzeResult 全文。
- J-T009-6（SVG 说明图）：证明面板的 SVG 只作示意（A≠B、F(A)=F(B) 两行文字），
  另有 <title>、aria-label 与下方文字说明；真正的断言以文字 + SHA-256 前缀为准，
  不以图为准。
- J-T009-7（390px 溢出修复）：初版 SVG 固定宽 360px 在 390px 视口下溢出 2px；
  改为 viewBox + max-width:100% 自适应后 overflow-x=0px（见 §1）。
